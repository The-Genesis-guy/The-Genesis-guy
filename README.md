## A note from the bookshelf

<details>
<summary>📓 Detecting a problem isn't the same as solving it</summary>

While working on the MLOps pipeline, I became interested in what happens after a drift alert. A change in incoming data deserves attention, but it doesn't tell the whole story by itself. The system also needs a way to record what happened, decide what to do, and recover if a change makes things worse.

That's the kind of detail I like getting lost in.

</details>
